# Artifact-sets

**Artifact-sets** — модуль для Foundry Virtual Tabletop, предназначенный для реализации механик и автоматизации игрового процесса.

## Установка

В Foundry VTT 14 открой **Модули** → **Установить модуль** и вставь эту ссылку в поле **Ссылка манифеста**.

> https://github.com/Sorati/Artifact-sets/releases/latest/download/module.json

## Основные возможности

### Наборы артефактов

Модуль добавляет специальный тип особенности — **«Особенность набора артефактов»**, позволяющий создавать игровые особенности, связанные с владением определёнными предметами.

Возможности системы:

- **Настройка требуемых предметов.** В особенность можно добавить список артефактов, необходимых для получения соответствующей особенности.
- **Перетаскивание предметов.** Требуемые предметы можно добавлять в список с помощью drag-and-drop.
- **Отображение предметов.** Список содержит названия и иконки предметов, а названия позволяют перейти к соответствующим предметам в Foundry VTT.
- **Автоматическая выдача особенности.** Когда персонаж выполняет условия набора артефактов, модуль автоматически добавляет ему соответствующую особенность.
- **Автоматическое обновление.** Модуль отслеживает изменения предметов персонажа и синхронизирует наличие особенности с выполнением требований.
- **Удаление автоматически выданной особенности.** Если персонаж перестаёт выполнять условия набора, созданная модулем особенность удаляется.
- **Сохранение происхождения предметов.** Система сопоставляет предметы персонажа с исходными предметами, в том числе при различии UUID экземпляра и оригинала.
- **Учет требований к настройке артефактов.** При проверке набора учитываются условия настройки предметов.

### Автоматизация

Система синхронизации работает автоматически при запуске мира и изменениях предметов персонажей.

Для предотвращения лишних операций предусмотрены механизмы синхронизации и защиты от повторного выполнения параллельных проверок.

Модуль самостоятельно определяет, какие особенности были выданы им автоматически, чтобы не удалять особенности, добавленные вручную или полученные из других источников.

### Интерфейс

Интерфейс набора артефактов оформлен с учётом визуального стиля Foundry VTT и сеттинга.

- Отдельная область для списка требуемых предметов.
- Возможность добавлять и удалять предметы при редактировании.
- Отображение списка в режиме просмотра без элементов управления редактированием.
- Возможность менять порядок предметов в редактируемом списке.
- Отдельное оформление пустого списка.
- Адаптация элементов списка для узких окон.

## Совместимость

- **Платформа:** Foundry Virtual Tabletop v14.
- **Система правил:** D&D 5e.
- **Версия системы правил при разработке:** 6.0.6.

## Принцип работы

1. Создаётся особенность типа «Особенность набора артефактов».
2. В её настройках указываются предметы, необходимые персонажу.
3. Когда персонаж получает все требуемые предметы и выполняет условия их настройки, модуль автоматически выдаёт ему связанную особенность.
4. При изменении инвентаря модуль повторно проверяет условия и актуализирует состояние особенности.

## Зависимости

Модуль рассчитан на работу со встроенными возможностями Foundry VTT и системы D&D 5e. Для описанной механики наборов артефактов сторонние модули не требуются.
